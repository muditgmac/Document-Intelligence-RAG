# API Documentation

Base URL (local): `http://localhost:8000`
Interactive docs: `/docs` (Swagger UI), `/redoc` (ReDoc) — auto-generated by FastAPI.

## Authentication

If `API_KEY` is set in the environment, all endpoints below require the header:

```text
X-API-Key: <your-api-key>
```

If `API_KEY` is unset (default for local dev), authentication is disabled.

---

## `GET /health`

Liveness check for orchestrators/load balancers.

**Auth:** none required.

**Response `200`:**
```json
{ "status": "ok", "version": "0.1.0" }
```

---

## `POST /documents/upload`

Upload and ingest a PDF document.

- **Method:** `POST`
- **Auth:** `X-API-Key` (if configured)
- **Content-Type:** `multipart/form-data`
- **Body:** `file` — a `.pdf` file, size ≤ `MAX_UPLOAD_SIZE_MB` (default 25MB)

**Example request:**
```bash
curl -X POST http://localhost:8000/documents/upload \
  -H "X-API-Key: $API_KEY" \
  -F "file=@handbook.pdf"
```

**Response `200`:**
```json
{
  "file": "handbook.pdf",
  "pages_processed": 42,
  "chunks_created": 118
}
```

**Error responses:**

| Status | Cause |
|---|---|
| `400` | Non-PDF file, encrypted PDF, no extractable text, or file too large |
| `401` | Missing/invalid `X-API-Key` |
| `429` | Rate limit exceeded |

## `POST /chat/ask`

Ask a question answered from previously ingested documents.

- **Method:** `POST`
- **Auth:** `X-API-Key` (if configured)
- **Content-Type:** `application/json`

**Request body:**
```json
{
  "question": "What is the refund policy?",
  "top_k": 5
}
```
`top_k` is optional (1–20, defaults to `RETRIEVAL_TOP_K`).

**Response `200`:**
```json
{
  "answer": "Refunds are available within 30 days of purchase [handbook.pdf, p.7].",
  "citations": [
    { "source_file": "handbook.pdf", "page_number": 7, "relevance_score": 0.91 }
  ]
}
```

If no relevant chunks are found, `citations` is `[]` and `answer` explains
that no relevant information was found — the LLM is not called in this case.

**Error responses:**

| Status | Cause |
|---|---|
| `422` | Empty or invalid `question` |
| `401` | Missing/invalid `X-API-Key` |
| `429` | Rate limit exceeded |
| `502` | Vector store query failed, or LLM generation failed after retries |
